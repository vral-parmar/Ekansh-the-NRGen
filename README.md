# Nessus CSV to HTML Generator 

This simple Python-Flask-based tool helps cyber security auditors generate a report and tracker at their fingertips.

Install the following before using Ekansh
> pip install flask, pandas, flask_sqlalchemy, flask_login, flask_wtf, wtforms, flask_bcrypt, numpy

## Ekansh-infra 
This folder helps in Nessus standard VAPT. 

## Ekansh-infra-D
this folder used if user is exported .csv with default configuration ie: there is a no column name(CVSS v3, MSKB, Metasploit).

## Ekansh-web
This folder helps to generate html files from standard CSV, (Note: You have to generate .csv file manually with the given template) 

## Ekasnh-compliance
This folder helps to generate Compliance reports from Nessus generated .csv (Note: You still need to edit .HTML file according to your preference).
